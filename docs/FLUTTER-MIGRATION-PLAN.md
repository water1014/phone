## 页面迁移顺序

1. 应用外壳：主题、路由、首页、侧栏、返回栈、安全区。
2. 聊天：消息列表、流式输出、工具/思考折叠、附件、独立聊天设置、会话搜索。
3. AI 服务：OpenAI-compatible、自定义 URL/Headers、各现有服务适配。
4. 记忆、世界书、联系人、日记、日历、安排、相册、收藏、音乐、记账等。
5. 生图、主动消息、主动生图、MCP、插件和 Android 系统能力。
6. 数据备份、旧数据导入、签名与升级链路。

## 质量门槛

- 每个页面独立路由和状态，不用单一巨型 Widget 承载所有功能。
- 每次迁移同时检查空数据、长文本、键盘弹出、窄屏、滚动和深色模式。
- 业务功能完成需有可复现操作验证；仅编译通过不等于功能完成。
- 数据导入前自动备份，导入后展示记录数并允许回滚。
