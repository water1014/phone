# 小窝 · UI 规范

> 一句话：**先把尺子定好，再画图。** 组件里不许写裸 px，数值只准从 `css/system.css` 取。

---

## 一、三个基础尺子

### 间距（`--sp-0` 到 `--sp-9`）

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--sp-0` | 2px | 图标与文字内侧微调 |
| `--sp-1` | 4px | 头像与名字之间 |
| `--sp-2` | 6px | 一排图标之间、标签之间 |
| `--sp-3` | 8px | **页面左右留白**、小卡内边距 |
| `--sp-4` | 10px | **消息行之间** |
| `--sp-5` | 12px | **卡片内边距**、区块底部 |
| `--sp-6` | 16px | **区块之间** |
| `--sp-7` | 22px | 大区块之间、弹层顶部留白 |
| `--sp-8` | 28px | 页首到第一块内容 |
| `--sp-9` | 40px | 大标题下方 |

### 字号（`--fs-1` 到 `--fs-9`）

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--fs-1` | 9.5px | 刻字、角标、水印 |
| `--fs-2` | 10.5px | **时间、英文小注、缓存率** |
| `--fs-3` | 11.5px | 说明、备注、旁白 |
| `--fs-4` | 13px | 次要正文、顶栏名字、导航 |
| `--fs-5` | **14.5px** | **气泡正文（全站主字号）** |
| `--fs-6` | 15px | 输入框、引导句 |
| `--fs-7` | 17px | 卡片标题 |
| `--fs-8` | 21px | 面板大标题 |
| `--fs-9` | 34px | 一屏唯一的大数字 |

**没有 13.5、没有 14.2、没有 12.8。** 中间想微调就换档，不要造新数。

### 圆角（`--rd-1` 到 `--rd-6`）

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--rd-1` | 6px | 气泡靠头像那**一个**角 |
| `--rd-2` | 9px | 小标签、提示块 |
| `--rd-3` | 13px | 思考块、小卡片 |
| `--rd-4` | 17px | **气泡** |
| `--rd-5` | 22px | 卡片、顶栏 |
| `--rd-6` | 26px | 大输入框、底部弹层上边 |
| `--rd-full` | 999px | 胶囊、圆形按钮 |

一个组件身上的角，必须在**同一档**或**相邻一档**。不准出现「上面 6 下面 17 左右 13」这种。

## 二、颜色层级（重点／次重点）

文字只有四级，越往后越往后退：

| 变量 | 用在哪 | 例子 |
|---|---|---|
| `--tx-1` | 正气：正文、标题 | 气泡里的字、卡片名 |
| `--tx-2` | 次要：说明、按钮字 | 「导出聊天」、设置项名 |
| `--tx-3` | 弱：导航、占位 | 输入框占位、底部 tab |
| `--tx-4` | 极弱：时间、单位 | `09:24`、`12 轮` |

**规矩**：一屏里 `--tx-1` 只给最重要的那几句。满屏都是 `--tx-1`，就等于没有重点。

面有三层：

| 变量 | 用在哪 |
|---|---|
| `--sf-1` | 气泡（最实） |
| `--sf-2` | 卡片 |
| `--sf-3` | 玻璃块（输入框、快捷词、浮层） |
| `--sf-me` | 她那一侧的气泡 |
| `--sf-sunken` | 凹陷区（思考块、输入底） |

强调色只有两种：`--ac`（暖紫，主）和 `--ac-warm`（暖粉，心、提醒）。**一屏最多两处。**

## 三、页面骨架（竖切一刀）

所有内页共用这一条骨架，从上到下：

```
  8px       ← --sp-3   屏幕顶/刘海下留白
  40px      ← --bar-h  顶栏
  10px      ← --sp-4
  ─────────────────   内容区（可滚动）

        卡片之间   12px   ← --sp-5
        消息之间   10px   ← --sp-4
        区块之间   16px   ← --sp-6

  ─────────────────
  8px       ← --sp-3   快捷词
  56px      ← 输入框
  12px      ← --sp-5   底部（+ safe-area）
```

内容左右一律 `--pad-x`（8px），最大宽 `--maxw`（640px），超出居中。手机不会宽过 640，所以这条在手机上等于「撑满减 8」。

## 五、三条铁律

1. **不准写裸 px。** 新写的样式，数值全从 `system.css` 取；实在没有合适的档，先改 `system.css` 加一档，再回来用它。
2. **字号不造新数。** 九档不够就说明页面结构有问题，不是尺子不够。
3. **一屏一个重点。** 一个大数字、一个 `--tx-1` 段落、最多两处强调色。剩下的全往后退。

---

## 六、怎么用

```css
/* 对 */
.bub {
  padding: var(--sp-3) var(--sp-5);
  font-size: var(--fs-5);
  line-height: var(--lh-3);
  border-radius: var(--rd-4);
  background: var(--sf-1);
  box-shadow: var(--sh-2);
  color: var(--tx-1);
}

/* 错 */
.bub {
  padding: 9px 13px;          /* 裸数值 */
  font-size: 14.5px;          /* 没走变量 */
  border-radius: 17px 17px;   /* 手写的角 */
  box-shadow: 0 3px 12px rgba(120,110,140,.06); /* 内联阴影 */
}
```
