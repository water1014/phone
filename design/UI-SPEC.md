## 六、分层三件事

**阴影只有两档**：`--sh-1` 卡片轻影、`--sh-2` 悬浮重影。优先用「底色差 + 线条」分层，别靠阴影。

**背景只有三层**：页面底（`--c-paper` + `--c-aura`）／卡片（`--c-card`）／悬浮（`--c-card` + `--sh-2`）。

**玻璃三件套**：

```css
background: var(--glass-bg);
backdrop-filter: var(--glass-blur);
box-shadow: inset 0 0 0 1px var(--glass-brd);
```

但前提是：**底下先铺 `--c-aura` 氛围光**。没有光可糊，玻璃就是一块白。

## 八、铁律

1. **不许写裸色值。** 色只从 `--c-*` 取。（纹理材质可豁免，须注释）
2. **不许造字阶。** 八档不够，说明结构有问题，不是尺子不够。
3. **一屏一个重点。** 一个大数字、一处 `--c-accent`、一段 `--c-ink1`。其余往后退。
4. **同一层用同一个角。** 不许「上 6 下 16 左右 13」。
5. **真机没验就写「待真机验收」。** 构建成功不等于功能成功。
6. **没有的功能不许硬加专区。** 没有就跳过。
